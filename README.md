# تطبيق Vivre - نظام إدارة وتعبئة وتوزيع المياه الذكي 📱💧

تطبيق جوال عالي الجودة مبني بواسطة **Flutter** لإدارة كافة عمليات التوزيع والمبيعات الميدانية وشاحنات النقل لمصانع وشركات تعبئة وتوزيع المياه.

---

## 🌟 الميزات والمواصفات الأساسية:

1. **الرابط الثابت للنظام (`https://w.rseha.com/`)**:
   - تم تثبيت الرابط الأساسي للنظام الميداني وقاعدة البيانات داخلياً ضمن ملف الثوابت `AppConstants.systemBaseUrl` بدون الحاجة لأي شاشات ضبط يدوية من المستخدم.

2. **قيد الموقع الجغرافي الإلزامي (Mandatory GPS Gate)**:
   - يتحقق التطبيق تلقائياً عند الإطلاق من تفعيل خدمة تحديد الموقع (GPS) ومنح أذونات الموقع.
   - في حال كان الموقع مغلقاً: يمنع التطبيق الدخول وتظهر شاشة أنيقة باللغة العربية تطلب من المستخدم تفعيل الـ GPS مع زر مباشر لفتح إعدادات الجهاز.
   - يستمع التطبيق لتغيرات حالة الـ GPS الحية (Stream) ويفتح الواجهة تلقائياً وبسلاسة فور تشغيل الموقع.
   - إذا قام المستخدم بإغلاق الـ GPS أثناء عمل التطبيق، يتم إيقاف الجلسة فوراً وإعادته لشاشة القفل الإلزامية لحماية دقة تتبع مسارات المبيعات والتسليم.

3. **تسجيل الدخول برقم الهاتف وكلمة المرور فقط**:
   - تم ضبط النظام ليعتمد على رقم الهاتف المحمول حصراً في تسجيل الدخول.
   - الحساب الرئيسي للمدير التقني:
     - **رقم الهاتف**: `01000333550`
     - **كلمة المرور**: `4574482`

4. **تكامل متقدم مع الويب وميزات الميدان**:
   - محرك `InAppWebView` فائق السرعة مع تمكين تسريع العتاد (Hardware Acceleration).
   - ربط مباشر لإحداثيات الـ GPS المحلية مع المتصفح الداخلي (`HTML5 Geolocation Bridge`).
   - دعم التمرير للتحديث (Pull to Refresh) وشريط تقدم تحميل أنيق.
   - شاشة معالجة انقطاع الاتصال بالإنترنت مع زر إعادة المحاولة الفورية.
   - إدارة زر الرجوع الفعلي (Hardware Back Button) للتنقل بين الصفحات السابقة قبل الخروج.
   - توجيه الروابط الخارجية (الاتصال الهاتفي `tel:`, رسائل واتساب `whatsapp:`, خرائط جوجل `geo:` و `maps.google.com`) إلى التطبيقات الأصلية مباشرة.

## 📂 هيكل ملفات المشروع (`vivre_mobile_app`):

```text
vivre_mobile_app/
├── lib/
│   ├── constants/
│   │   └── app_constants.dart       # الثوابت ورابط https://w.rseha.com/ وألوان الهوية
│   ├── services/
│   │   └── location_service.dart    # فحص الـ GPS الحي والأذونات وإعدادات الموقع
│   ├── screens/
│   │   ├── splash_screen.dart       # شاشة البداية والأنيميشن المائي الأنيق
│   │   ├── gps_gate_screen.dart     # شاشة القفل الإلزامية لتشغيل الـ GPS
│   │   └── webview_screen.dart      # الشاشة الرئيسية وعرض النظام والتنقل
│   └── main.dart                    # نقطة انطلاق التطبيق وإعدادات اللغة العربية والسمات
├── android/
│   └── app/src/main/AndroidManifest.xml # أذونات الموقع والإنترنت والكاميرا
├── ios/
│   └── Runner/Info.plist            # نصوص أذونات الموقع باللغة العربية
└── pubspec.yaml                     # حزم ومكتبات المشروع
```

## 🚀 كيفية تشغيل وبناء التطبيق:

### 1. تثبيت الحزم والمكتبات:
افتح مجلد `vivre_mobile_app` في سطر الأوامر (Terminal) أو VS Code ونفذ:
```bash
flutter pub get
```

### 2. تجربة وتشغيل التطبيق على الهاتف أو المحاكي:
```bash
flutter run
```

### 3. بناء ملف APK الإنتاجي المباشر للأندرويد:
```bash
flutter build apk --release
```
سيكون ملف الـ APK الجاهز للتثبيت متاحاً في المسار:
`build/app/outputs/flutter-apk/app-release.apk`

### 4. بناء حزمة تطبيق الآيفون (iOS):
```bash
flutter build ipa --release
```
